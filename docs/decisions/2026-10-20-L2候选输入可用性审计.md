# L2 候选输入可用性审计

v2 输入证明增加 `l2FieldAudit`，区分“数据库有列”“本次有值”和“批准模型接受”。旧读取器只检查最低必需列；可选列缺失、全空和非有限值没有逐字段记录，事后难以判断评分实际用了什么。

`L2ScoringInputContract` 为实际 SQL 投影和审计共用 29 列清单。最低要求仍为原来的 8 列，不扩大正式输入要求。字段含义复用 `L2DailyFeaturesDataset`；未登记的历史候选列明确列出缺口，不按名字推断单位。报告统计原始有界快照中的缺键、null、有限数值、NaN/Infinity 和非数值类型，保留真实零值。

记录现行评分规则：`daily_amount` 的基础评分值来自关联行情；`amount` 在行情提供同名列时被覆盖，缺行情仍走原左连接规则。最终增强列可能保留原始 L2 值，两处不能视为同一来源。`turnover_rate` 不从日行情补入基础评分；`buy_aggressiveness` 和除以 `clean_amount` 的特征保留原公式，量纲仍待独立验收。

审计不修改输入、数值和阈值，不写库，不重算或修改历史证明。只有 v2 新快照增加字段；v1 的证明、行编码和摘要路径保持原样。`modelAcceptanceVerified=false`、`sourceCoverageVerifiedByThisAudit=false` 明确保留，不能因最低结构检查通过就认定模型输入齐备。

本次没有完成金额、币种、比例尺度的完整字典，也没有取得生产训练原件或独立参考。新统计不等于生产输入已经验收；正式物理迁移、MV 切换和三项退役表删除仍未执行。
