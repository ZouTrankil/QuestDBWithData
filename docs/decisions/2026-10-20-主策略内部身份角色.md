# 主策略证券与汇总身份分开

`ScoreRow.symbol` 原来同时存证券代码和 `MARKET`、`ETF_UNIVERSE` 标签。不能直接把这几个标签改名为 `instrumentCode`，否则会把汇总范围冒充证券。

现在证券行使用 `instrumentCode`，汇总行使用明确的 `AggregationScope`，二者只能提供一个。复制特征和评分冻结会保留这个角色；内部算法用 `groupingKey` 分组，不能将它当作对外证券代码。将汇总行发布为证券行会失败。

ETF 基础资料使用 `instrumentCode`；持仓分成 `etfCode`、`constituentCode`、`announcementDate`、`reportPeriodEndDate`。`holdingMarketValue` 对应 `mkv` 的元，不能用 `amount` 股数代替。`holdingMarketValueRatio` 原样接收 `stk_mkv_ratio`，按原算法在篮子内归一化；本次没有认证来源未说明的尺度或分母，也没有新增换算。

当前正式产物仍是旧协议。`legacyV1Frames` 明确输出原来的 `trade_date/ts_code`，汇总覆盖不输出证券键；没有改写旧 Parquet、批准摘要或历史计划。新增日频产物的 `instrument_code`、覆盖协议及 Python 读取端仍需按任务 07 完成显式版本升级，不能把这次内部模型调整当作新版发布已经接通。

主策略模块 126 项回归通过，包括原评分样本、汇总身份保护和 v1 输出适配；架构、模块边界及主策略发行包通过。未运行正式评分发布或批准材料的实物比对。
