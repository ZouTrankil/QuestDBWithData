# 来源字段注释共用一份资料

CN 的 Tushare 字段说明保存到市场资源 JSON，由生成器写到已有存储投影的中文注释，同时通过市场 SPI 提供给公共目录接口。离线导出读取这份 JSON，不需要账号、数据库或网页服务。

公共 core 只增加通用 `SourceField` 值类型，市场提供可选的逐列说明；公共引擎不依赖 CN 或 Tushare 实现。目录列结构新增 `sourceDocumentation`，保留原五参数构造方式。原 `meaning` 和时间契约优先，来源说明只补缺。

使用 `VERIFIED_SOURCE`、`LOCAL_RULE`、`UNVERIFIED` 区分官方输出字段、本地规则与未核实字段。核对公开文档不等于真实来源验收。文档里的 `str`、单位和日期格式不改变 Java 或 QuestDB 类型，也不驱动数值换算、补字段、回填或迁移。

保留原模型成员、顺序、schema 快照日期、数据版本、物理目标和恢复协议。只更新既有生成模型注释时，不清理其他模型；完整生成先校验代码与说明，再统一写入。
