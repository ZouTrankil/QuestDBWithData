# 同花顺资金流只放行正式有界补数

正式 `moneyflow_ths` 已有历史行，但没有足够的原来源覆盖凭证。保留原 v1 作业、字段、物理目标和恢复协议，增加精确同名准入；正式入口只允许明确日期的 `BACKFILL`，不从旧行推导增量检查点。

writer 新增独立配置，兼容回退原配置，默认目标不变。这样既保留原部署的覆盖方式，也能显式选择正式表；不通过修改根默认值顺带改变读取目标。

逐批核验之后必须核对整日。已发送而整日不符时，原锁和运行保留未决；下一日来源失败仍可按原请求恢复已验证范围。隔离 DDL 继续拒绝正式名，没有改表或启用第二个生产 writer。

来源、限制和实测结果见[同步说明](../moneyflow-ths-sync.md)。正式写入及日批启用仍须逐表确认原生产归属和未决记录。
