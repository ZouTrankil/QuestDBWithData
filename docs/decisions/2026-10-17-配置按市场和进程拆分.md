# 配置按市场和进程拆分

所有运行配置继续集中在根 `config/`，不用在每个模块再维护一份。

`application.yml` 放公共连接、来源客户端和日志默认值，按相对路径导入 `markets/` 与 `apps/`。市场文件放时区、共用路径和后续市场规则；应用文件放端口、存储、任务和会话设置。公共库没有独立配置，尚无实际进程的美股和 BTC 不建空应用配置。

沿用 data、main-strategy、batch、l2 四个入口 profile，自动带上 market-cn。main-strategy 还带上 data，因为正式策略复用 A 股数据组件。数据 CLI 可以读取策略参数，但不因此启用策略日批。测试直接装配 A 股组件时也要明确启用市场 profile。

公开默认值保持原属性名和实际参数。加载公共配置后，只启用对应的市场与应用；本机覆盖最后导入，环境变量和命令行仍可覆盖。市场时钟未装入配置时使用 core 的标准默认值，不加载另一市场业务。

Gradle 把同一棵公开配置目录放入应用 jar 和发行包，按相对路径读取；部署必须带完整目录。本机覆盖和示例不打包。加载、隔离、覆盖和目录迁移通过实际 Boot 配置解析测试，另核对模块边界与发行包。
