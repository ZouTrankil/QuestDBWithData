# 主策略标准输入与模型适配

v2 快照采用标准身份和日期，原评分模型通过明确的 v1 特征边界读取。这样可以升级输入协议，同时保留已批准模型的特征名与数值。

`StrategyInputRows` 复用已有 Dataset 定义，把来源角色的物理名映射为逻辑名。业务日期解析为 `LocalDate`，真实时刻保留 UTC，ETF 基础资料的 epoch 单列为 `technical_partition_marker`。ETF 持仓区分 ETF、成分、公告日和报告期；数量、市值、比例只明确名称，不缩放或填值。未知日期、错误技术占位和列名碰撞直接拒绝。

`QuestDbStrategyInputs` 按覆盖协议选择快照版本，先核验标准键，再按原历史证据选取名称、行业和市场状态。`PointInTimeHistory` 显式适配输入和输出，不改原历史协议、决策截止或 `availableAt`。v1 继续使用原行和摘要编码。

`MainStrategyDataService` 将标准快照适配给现有模型，发布输入仍保留标准列。宽行改名共享不可变单元，不暴露可写数组或外部 Map。保留参考输入经过真实映射后，完整评分输出与原路径相同；这只验证映射行为，不能代替生产原件验收。

新版发布器与实际 Python 消费者仍未接通。v2 在评分与市场包别名更新前明确停止，不能先发布旧评分再让新版市场包失败。未进行正式发布、物理表迁移或生产批准材料升级。
