# 标的名单正式补数使用独立窗口基线

正式 `margin_secs` 已有1618079行，超过原隔离 v1 的百万行全表快照预算。为了让单日补数能在真实旧表执行，新增作业 v2，数据版本和物理结构不变。没有扩大原预算，也没有改变 v1 冻结参数的含义。

v2 用明确的 `baselineScope=DATE_WINDOW` 冻结本次日期窗的旧行数、全部键值摘要和范围上下界。窗口最多31天，来源日期由完整冻结日历确定；读前后核对同一物理代和稳定 WAL。范围外历史既不认证也不覆盖。

正式只允许明确 `BACKFILL`，不从旧数据建立增量检查点。旧隔离 v1 继续原恢复协议；版本或目标不匹配即拒绝。新 writer 配置兼容旧覆盖方式，默认不切换，也不自动启用日批。

逐日来源缺旧键时先拒绝发送；发送后整日不符保留未决运行和原锁。操作、限制及证据见[同步说明](../margin-secs-sync.md)。正式原生产归属、补数及消费者仍需逐表验收。
