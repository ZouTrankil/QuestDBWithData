# 利率观测正式采集

三张利率表已有原来源契约和 v2 读取映射，但没有正式同步 owner。新增 owner 后由它登记同一 v2 数据集的读取和写入能力，原只读模型常量、日期列、业务键及期限别名保持不变，移除重复的只读登记 Bean。

复用原来源的单日请求、合法空源和质量规则。每次最多 31 个自然日，不按 SSE 或固定月报价日猜缺口。真实时间仍只用于观测记录，利率日期仍是业务日期。

宏观和利率共用单日期键标量端口，只接受明确的日期键及 DOUBLE/STRING 字段。逻辑键通过映射找到原物理列，所有期限列显式引用；只读定义不能调用发送。端口不建表，仍做完整字段回读、WAL 和物理身份验证。

日批默认关闭，仅数据 API 常驻进程按配置启用，有限 CLI 和主策略不启动。来源空响应不能证明某期报价已齐；历史可用时刻也不能从日期标记猜出。正式接管继续等待原部署状态和实际写入验收。
