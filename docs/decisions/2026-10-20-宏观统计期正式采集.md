# 宏观统计期正式采集

六张宏观统计表已有来源契约，但没有正式 owner，Batch 只能写隔离表。真实探测已取得库中缺少的 2026 年 9 月月报和三季度 GDP。

在 CN 数据模块新增正式 owner，复用 `markets/cn/source` 的字段、请求、统计期覆盖和原文归档规则；社融按官方文档新增同类契约，原 41 条来源保留原件对照。数据模块因此显式依赖同市场来源模块；不依赖 Batch 执行器，不改变其隔离限制。模块边界清单同步登记。

正式目标仍是原同名表、YEAR/WAL 和原统计期键。字段通过原契约投影，日期文本明确编码为 UTC 午夜日期标记。来源全期完整、全部值回读、WAL 和物理身份通过后，才接受完成记录。

日批每天重查有限修订窗口，默认关闭，只由数据 API 常驻进程托管。有限 CLI 和主策略不启动这项调度；更早历史用明确范围补数，未决运行不自动重发。

当前只支持六张已核对布局的统计表，没有借此批量开放其他来源写入。正式接管仍须原部署状态和真实写入验收。
