# 按市场拆分业务

业务归 A 股、美股、BTC，各自管理模型、来源、清洗、日历和应用。主策略和实时 L2 归 A 股，进程继续分开。

通用引擎分 source、questdb、batch 子项目，A 股库分 source、data、batch 子项目。这样 Batch 不加载 PGWire，实时 L2 也不引入完整离线链路。嵌套项目的组件坐标、jar 名和 build 路径都使用完整项目路径，避免同名 source/batch 冲突。

core 只保留 JDK 契约。Jackson 存储投影留在引擎，A 股 DTO、L2 字段和日行情语义放回市场库。

市场通过 SourcePolicyProvider 注册来源和质量规则；美国利率不再由 A 股注册表持有。唯一写入方、表名、字段、任务身份、摘要算法和 Quartz 旧类名保持兼容。

时间使用 UTC 时刻加市场业务时钟。纽约使用地区时区，上海使用上海时区，BTC 默认 UTC。历史 UTC 零点日期标记不改值；未决运行保留原日期和时区，不自动重发。

这次调整不代表美股全市场或 BTC 数据链路已完成，也不代表旧财务增量已经接管。
