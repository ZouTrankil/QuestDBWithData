# ETF 与 BTC／ETH 启动研究计划

记录日期：2026-10-29。目标：用现有的小规模数据完成可复核的策略基线，再决定是否扩充数据。

## 当前结论

- 美股先做 SPY、QQQ、IWM、TLT、GLD 的日频实验，USO 作为扩展对照。原始价格、复权价格和公司行动字段已有，完整性与口径仍待验收。
- BTC 原生六表具备现货趋势、资金费率信号和现货—永续对冲研究的核心输入。先做现货基线，再处理多表实验。
- ETH 目前确认的是 `crypto_ohlcv` 中的现货／永续行情。先做现货趋势和 BTC／ETH 轮动；未确认 ETH 资金费率、标记价及指数价，不安排 ETH 资金费策略。
- `crypto_ohlcv` 的 WAL 状态待查。该问题阻塞依赖此表的正式实验，不阻塞独立通过验收的 ETF、BTC 原生表实验。
- 暂不扩采 ITCH、分钟线、订单簿、期权、大量币种或全市场股票。第一阶段不做高频交易、跨交易所成交套利或复杂深度学习。

## 证据与完成状态

本目录的数据数量和实库状态来自用户在本次会话提供的只读查询结果；本次文档整理没有重新连接 QuestDB，没有下载、修复或写入正式数据，也没有运行回测。

“已有数据”只表示用户查询确认存在，不表示字段质量、区间完整性、历史可见性或下游适配已验收。所有未执行任务保留待办状态；策略没有收益也可以是有效实验结果。

后续在 [tasks.md](tasks.md) 的现有任务下更新状态、证据入口和阻塞，不另建重复清单。不要把内部服务地址、凭据或个人信息写入本目录。
