# ETF 与 BTC／ETH 启动研究计划

执行日期：2026-10-30。目标：用现有的小规模数据完成可复核的策略基线，再决定是否扩充数据。原计划日期为 2026-10-29。

## 当前结论

- 六只 ETF 和十只核心股票共 80054 条日线完成逐日期、完整字段及原 Native 对照；五只 ETF 的 E0／E1／E2 已运行，USO 只做数据与公司行动检查。
- BTC 原生日线可做现货基线；小时线、mark／index 与资金费仍有明确缺口或未知项，多表实验继续阻塞。六表的检查通过范围分别记录，不合称全历史完整。
- `crypto_ohlcv` 的八个产品、十六格共 370198 行完成验收；ETH H0 和 BTC／ETH H1 已运行，不引入不存在的 ETH funding。
- 两张异常表经备份及受控 `REBASE WAL` 恢复，当前均为 `2/2`、无缓冲、未挂起。新物理身份与旧 Native 的历史身份分别留证。
- 用户要求去掉的对象是 ITCH 原始订单流：450836 条已完整归档后移出正式库，采集入口默认禁用。既有分钟线、A 股 L2 和日线／小时线的时间精度保留；它们不参与本轮日频实验。

## 证据与完成状态

本轮已连接实库，按用户明确授权修复 WAL、退役 ITCH，并运行固定的历史回放。原件、备份、完整字段、物理文件与 WAL 分别核对；没有为了启动追补末尾日期，也没有修改历史来源失败状态。

十四个实验及基准、三档成本共 42 组均保留日收益、资金、权重、交易、逐年和分阶段结果。历史数据曾否用于调参无法独立确认，因此本轮明确属于开发回放，不把 2024 年以后称为未见留出期。后续真实未见期从 2026-10-30 起，尚无成绩。
