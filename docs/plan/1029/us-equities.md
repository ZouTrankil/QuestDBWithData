# 美股：启动数据范围与验收

## 1. 启动范围

主实验使用 SPY、QQQ、IWM、TLT、GLD，日线输入、月末决策、下一交易日开盘执行。USO 单独加入做扩展对照。SPY／QQQ／IWM 都属于美国股票敞口，五只等权并不代表五种独立风险。

不依赖全市场股票采集完成。16 只分钟线中的其余 10 只股票名单尚未提供，本轮不擅自选取蓝筹股票池。

## 3. 必做检查与验收

| 检查 | 具体内容 | 验收标准 |
|---|---|---|
| 来源与唯一键 | 确认表字段、供应商、标的身份、日线日期定义；检查每标的每交易日是否唯一 | 重复为零，或逐条解释并按既定规则处理；不能任意取最后一条 |
| 交易日完整性 | 对照适用的美国交易所日历，列出缺失、多余日期、上市前记录及停牌等例外 | 启动窗口内每个异常有明确处置；不得直接前填缺失 OHLC 制造可交易行情 |
| 价格与成交量 | 检查 null、非有限值、非正价格、负量、OHLC 大小关系、连续零量平价和异常跳变 | 无未解释的结构错误；极端市场收益不因数值大就删除 |
| 公司行动 | 抽查 TLT 除息日前后、USO 拆股前后；确认 split_factor 方向及原始／复权量含义 | 复权收益与公司行动可核对，无机械拆股跳变、无重复计息 |
| 复权口径 | 确认复权是否覆盖分红和拆股；比较复权收益与原始价格加公司行动计算 | 差异可解释并记录容差；不得混用原始开盘价与复权收盘价算收益 |
| 历史可见性 | 比例型信号使用截至当日的回看窗；金额、股数、流动性采用当时原始口径 | 无未来数据进入决策；固定供应商数据快照并声明非历史 vintage 复原 |
| 执行与分红 | 收盘产生信号，下一交易日执行；区分总收益研究与现金账本 | 用复权收益时不再加分红；除息应收不当成支付日到账的可用现金 |
| 成本 | 固定佣金、最低费用、滑点、整股／碎股约定及现金处理 | 每笔成交和组合收益可复算；成本来自明确假设，不宣称实盘精度 |

USO 官方记录为 2020-04-28 进行 1∶8 反向拆股，可作为抽查锚点。USO 含期货换月影响，不能把基金收益解释为现货油价收益。[官方资料](https://www.uscfinvestments.com/uso)

## 4. 研究窗口与最小补充

- 数据库存量截至 2026-10-23，暂不为了启动追补最新几天。
- 2006 年数据可用于预热。正式评分起点由最长回看窗和验收后的可用日期确定；主实验与含 USO 的对照必须使用同一评分区间。
- 提议冻结 2024-01-01 至验收截止日作为最终留出期，之前用于规则开发。执行前必须确认没有据此期间表现调参；若已使用，应另行确定留出方案并记录，不能称为未见数据。
- 现金基线先采用零收益并明确标注。之后可用可验证的短债总收益或利率代理做敏感性对照。TLT 不作为现金替代。
- SGOV 2020-05-26 成立，不能填补其上市前行情或伪造二十年实绩。[官方资料](https://www.ishares.com/us/products/314116/ishares-0-3-month-treasury-bond-etf)
- 宏观实验仅补已有 FRED 中缺少的 DGS2、DGS10；VIX 复用已有数据。核对单位、公布时间、修订版本，按可见时间向后匹配，不能按观察日期提前使用。
- 暂不需要 CPI、GDP、完整 ETF 持仓、分钟盘口或其他 ETF。未来研究这些对象时再增补。
