# 下载官方归档并校验

依赖 00。状态：首版已完成。581 个计划归档已校验并处理；截止月资金费率月包缺失，由官方 API 补齐。原文、版本和错误保留。

## 做什么

复用现有下载和校验，补齐六组数据的文件计划、状态记录和中断恢复，不另建重复下载工程。

1. 完整月份优先月包，未出月包的尾部按该数据集实际提供的日包补齐；资金费率不能假设也有同样日包目录。
2. 保存 ZIP、官方 CHECKSUM、URL、取得时间、字节数和 SHA-256。原文件按版本保留，不原地覆盖。
3. 文件先下载到临时位置，校验后再登记完成。记录失败、未发布、来源不提供和待重试，404 不自动算合法空范围。
4. 限制并发、请求、文件和解压大小；拒绝 ZIP 路径越界。重启复用已核验文件，损坏临时文件重新下载。
5. 新文件任务包含数据类型和周期，旧任务按原版本读取，避免六组数据的任务 ID 撞在一起。

## 交付和验收

同一范围重复运行不重复下载有效文件；断网、截断 ZIP、错 CHECKSUM 和未发布文件有明确结果。文件状态不冒充数据已通过验收。
