# 直接显示哪些表没更新

状态：待执行。使用任务 09 查到的真实运行记录。

## 现在的问题

现在只看到表存在、最新日期。数据没更新时，还得翻代码和日志，才能知道原因。

## 要做什么

在现有目录或状态接口中显示：

- 数据最新到哪天。
- 同步任务上次什么时候成功。
- 现在卡在哪里：没开、暂停、写错表、等配额，还是运行失败。
- 下一步该做什么。

日行情、月季数据、公告和历史表分别判断。未来解禁日、技术占位日期不能当成最近同步时间。

## 怎么算完成

能直接找出该更新却没更新的表，并看到原因。来源已更新、但视图或评分没更新，也能分清。查不到就显示未知；查询本身不补数、不刷新、不解锁。

优先读元数据和运行记录，不每次扫描整张大表。

## 修改 prompt

```text
先读项目规范。复用现有目录和 status，显示数据日期、最后同步成功时间、失败原因及处理建议。按来源频率判断是否过期，区分原始数据、视图和评分。缺记录或查询失败显示未知；只读查询，不触发补数、刷新或解锁，并验证这些情况。
```
