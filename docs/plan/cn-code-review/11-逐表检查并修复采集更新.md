## 每张表怎么做

1. 查来源、更新频率、负责程序和实际写入表。
2. 看最近一次成功和报错，查清是没开、写错表、等配额，还是来源没有新数据。
3. 复用已有采集程序修好，一次只处理一张表。财务请求太多就分批，配额用完或重启后接着跑。
4. 核对来源范围、证券、全部字段值和 WAL，再检查下一次更新是否正常。最大日期变新不算验收完成。

已发送但结果不确定的任务按原流程恢复，不自动重发或解锁。已有补数记录先核对，避免重复执行。

## 怎么算完成

每张表留下：最新数据日期、上次成功时间、实际原因、修了什么、验证结果。查不到的写“待查”。纯历史数据标明只留历史，不硬加日更。

结果放回现有目录或状态接口，能直接看到哪张没更新、为什么，不另开一个监控项目。
