# 财务数据分批更新

先完成任务 09。状态：待执行。

## 现在的问题

财务日批默认关闭，运行时有没有开还没查清。

现有流程一次扫很多证券和报告期。5,000 只股票 × 5 个季度 × 5 条来源，至少要请求 125,000 次，默认一轮只允许 1,000 次。直接开调度也跑不完。

## 要做什么

把 `cashflow`、`income`、`express`、`forecast`、`fina_indicator` 拆成小批次：

- 按来源、股票、报告期分批，记录每批进度。
- 优先处理近期披露，再回查旧报告的修订。
- 配额用完就等待，下次继续；重启不从头跑。
- 继续用原财务同步代码，不增加另一套写入程序。

没有来源映射的历史列不补造值。公告不是每天都有，先查真实披露，再判断缺了什么。

## 怎么算完成

验证新增公告、旧报告修订、配额耗尽和中断恢复。每批核对来源、完整键值和 WAL；全部批次通过，才能说该范围完成。
