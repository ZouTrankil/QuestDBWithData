# 衍生品与被动资金：数据获取和研究计划

状态：待执行，2026-11-10。目标是用有限数据检验市场状态和后续收益的关系，不预设“3% 优势”存在，也不把代理指标当成真实资金流。本次只核对文档与公开来源，没有下载数据、查询实库或运行回测。

## 先纠正口径

- 买方买入 Put 或 Call，卖方持有空头期权，通常是 **short Gamma**；买方卖出期权，交易对手持有多头期权才是 long Gamma。Long Put 本身是正 Gamma、负 Delta。做市商实际净仓位还受其他客户、期权组合和跨市场对冲影响，不能只看某一笔交易推断。
- 持有正 Gamma 且近似 Delta 中性的主体，价格上涨后倾向卖出标的、下跌后倾向买入；负 Gamma 的方向相反。实际对冲频率、工具和库存约束会改变效果。
- 每份未平仓合约都有多空双方，单靠 OI 不知道哪一方是做市商，也没有公认的“全市场 Gamma 总和”。Gamma flip 是模型和仓位假设下的估计值，不是可直接观测的临界点；跌破也不必然暴跌。
- CTA、波动率目标和风险平价有不同模型、再平衡频率、杠杆限制和执行方式；不能假设跌破均线必定市价反手，或所有基金同步等比例去杠杆。VIX 是隐含波动率，已实现波动率来自历史收益，两者不可混用。
- VIX 期限结构恢复正斜率并不证明被动卖盘已经出清；散户净买入、Put 偏斜和 CDS 均不能单独证明机构派发或某个行业必然下跌。下列指标是待检验的条件，而非交易建议。

## 分阶段任务

### 1. 免费日频风险状态：先完成

- [ ] 清点 SPY、QQQ、债券 ETF、VIX 的真实可用范围及逐日缺口；下载前检查 Cboe VIX9D、VIX3M 的实际 CSV、历史起点、更新方式及许可。冻结原文、URL、取得时间、摘要和可见时点。缺数据明确阻塞，不填造。
- [ ] 计算 `VIX/VIX3M` 和 `VIX9D/VIX`；以比值小于 1 为该对期限的正斜率，等于 1 单列。计算 20 日年化实现波动率（对数日收益的样本标准差乘 √252）、20/50/200 日均线及 60 日股债收益相关性。SPY 和 QQQ 分开，信号收盘后才可用。
- [ ] 设计固定的高波动、趋势和股债相关性条件，比较下一交易日及未来 5、20 日收益、波动、最大回撤与无条件基线；报告各状态样本数、缺失日、不同历史阶段及重叠事件处理。先冻结阈值，保留全部结果。
- [ ] 交付可执行中文 Notebook：数据来源、可运行代码、图表解释、缺口、假设和结果限制；复用 [research Playbook](../../../research/README.md) 与现有回放器，核实所需能力后才扩展。期权数据未取得时，本阶段不产出 Gamma 结论。

### 2. 资金行为代理：依赖阶段 1 的价格数据

- [ ] 获取 CFTC 股票指数期货对应的 TFF Futures Only 历史，固定合约代码、类别、单位与公布时间；用实际发布日历处理节假日及规则变更，无法确认的日期标为不可用。观察净持仓及变化，**不称为 CTA 仓位**。
- [ ] 构建明确标为模拟的规则：例如 20/50/200 日趋势信号和 `目标波动率 / 已实现波动率`，另设仓位上下限、零波动保护和月末再平衡。用不同窗口做预登记敏感性分析；不得解释为真实基金订单。
- [ ] 比较股债相关性、模拟风险预算和未来收益；不能从相关性直接推导实际 VaR 或清算。验收为来源、时点和公式可复算，模拟结果与 COT 发布前不可见数据隔离。

### 3. 期权 Gamma / Skew 样本：依赖授权来源

- [ ] 先取得单标的、有限日期的真实样本，核实下载费用、许可、时间戳、历史覆盖、合约乘数、调整合约、到期时间、报价质量、OI 发布时点与 Greeks 定义。仅在通过容量预算后扩展；未取得样本时记录阻塞。
- [ ] 建立逐合约 Gamma 暴露情景，明确多空符号假设、Delta 对冲工具、乘数、标的价格、每 1% 价格变动的单位。至少比较不同的做市商持仓符号假设与到期范围，报告假设敏感性及无有效零点的情况。OI 未知方向，结果只叫**假设 Gamma 代理**。
- [ ] 以同期数据的真实可用时间形成信号，区分前一日 OI 与当日 15:45 Greeks；不可将盘后 OI 用于当日盘中判断。拟合价格曲线计算零点时写明波动率曲面、到期时间等重估假设；不能声称真实日内 flip 或强制成交量。
- [ ] 对同到期、接近预设 Delta 的 Put/Call 比较 IV，记录价格失真、缺报价及插值限制。若只有日终快照，结论仅限日频，不能证明当日执行流。

### 4. 检验组合信号：依赖阶段 1 和 3

- [ ] 固定四组：无条件、仅期限结构、仅假设 Gamma、两者同时满足；使用相同窗口、样本、信号可见时间和下一交易日执行价。与买入持有、固定低仓位及简单均线比较，计入明确的交易成本情景。
- [ ] 按时间切分开发与样本外区间，事件研究避免同一次行情重复计数；报告收益、最大回撤、波动、换手、成本、风险暴露、信号数量及不确定性。检查数据泄漏、多重试验和参数敏感性；区分相关、预测与因果。
- [ ] 验收：完整展示全部预登记对照及失败结果；不能从单一回测或名称推断有 3% 优势。若样本、真实时点或信号数量不足，结论写“证据不足”。

## 容量、发布和边界

研究数据原件、派生表和证据合计沿用 300 MB 硬上限、单文件 25 MB；包含已有数据的占用，下载前核实剩余额度，流式超限即停止。更大数据先记录对象与预算，交由用户处理。数据和运行环境占用分开报告。期权数据先限标的、日期和字段，确认许可后使用；不得将有再分发限制的原件提交仓库。

研究准备和 Python 只读 QuestDB；如后续要正式采集，另按美股 Java 入口和既有来源凭证、业务键、WAL、回读及恢复协议实施。每类数据记录 `observation_date`、真实事件或快照时间、`available_at`、来源及版本，时间点存 UTC，业务日按纽约日历。研究快照和正式入库验收分开报告。本计划不启动采集、不写正式库、不进行交易。
