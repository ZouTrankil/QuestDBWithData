# 策略横向比对与归因

日期：2026-10-20。性质：研究比较能力。依据：[美股需求原文](../../../markets/us/plan.txt)。本文件是待执行目标，不代表已取得回测结论。

## 背景与当前缺口

七基金组合、不同版本 Hi5 和 TQQQ 来源策略各自能回测，不代表结果能直接横向比较。样本期、追加资金、成本或分红口径不同，都可能让排名失真。目前缺少一套明确的统一比较输入和输出约定。

本任务只负责比较和解释已明确的策略版本，不负责调度其他任务，也不另写一套策略引擎。缺少有效输入的策略显示不可比较原因。

## 要达成的具体效果

选择多个策略版本及日期范围，执行一次比较，就能看到同条件的净值、回撤、年度收益及风险成本对照，并定位收益和风险差异来自哪些资产、持仓区间或交易成本。

用户可以分别比较“一次性投入”和“相同定投计划”两种情景，区分投入本金与投资收益；能查看共同样本期的公平对照，也能查看明确标记的各策略完整历史。不预设某个策略是赢家。

## 实现什么，交付什么

- 提供 Python 比较入口和配置样例，可选择七基金组合、Hi5 各版本、TQQQ 各来源策略，以及 SPY/QQQ 基准；每项绑定明确的策略版本和数据版本。
- 统一初始资金、外部现金流日期/金额、估值日期、交易成本假设、分红处理及指标计算约定；策略自身不同的信号、仓位和调仓规则保留，并展示实际成本差异。
- 主比较使用共同有效样本期。不能只机械取首尾交集，还需检查区间内缺数据及结果有效性；输入口径不一致时，按相同约定重新运行或拒绝比较，不直接拼接旧汇总指标。不得填造上市前价格或静默前向填充成可交易数据。
- 输出统一起点的时间加权净值曲线、回撤曲线、逐年收益、滚动收益和对照表。定投另展示累计投入、账户价值及适用的资金加权收益，不能把账户总额增长当作年化收益。
- 对照表至少包含区间收益、年化收益、最大回撤及发生/恢复区间、年化波动、换手、累计成本和数据覆盖。Sharpe 等需要额外假设的指标，明确无风险利率来源、频率及年化方式；资料不足标未知，不偷偷按零处理。
- 结合每日持仓、收益和成本，解释资产收益贡献、主要回撤区间与成本影响；归因贡献应能与组合收益按约定核对，不把相关性解释成因果。展示不同市场区间和预先固定的成本情景，避免事后只挑有利区间。
- 交付可运行入口、比较配置、可机读明细、中文图表报告及运行清单。清单保留输入摘要、策略/数据版本、样本期和所有假设；研究对 QuestDB 只读，结果保存本地文件或 SQLite。

## 怎样验收

- 同一策略与自身比较，各项差异为零；改变成本后，净值与成本账变动可核对。
- 同一输入重复运行，比较结果可复现；汇总指标从独立参考小样本或已有独立实现核对，不只比较同一引擎自产结果。
- 一次性投入与定投结果分开；同一定投计划中的基准接受相同外部现金流，缺数据策略有明确原因。
- 共同样本期和各自完整历史分别标识，不用不同日期范围的年化数字直接排序；有效期为空时拒绝生成排名。
- 每张表和曲线能追溯配置、数据及假设，归因与账户明细一致。未恢复的回撤、无解的资金加权收益等情况保留状态，不补成零。
