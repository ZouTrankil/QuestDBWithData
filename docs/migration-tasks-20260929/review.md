## Review后补强的规则

1. 首次0行不能证明写入闭环。默认增量、有数据才写，必须有非空真实来源写入和实际QuestDB逐键逐字段回读；后续无新增单独记verified_empty。
2. 限流必须在每次HTTP尝试边界共享；配置与装饰器不同不能直接取高值，财报VIP路径不能默认受普通接口装饰器约束。
3. Python宏观整段请求、FRED整份CSV后过滤、reference缩到7天仍可能触顶、daily网络错误返回空表均列为迁移风险，不能原样复制后声称合格。
4. cyq_chips现有键仅代码/日期，需核实价位维度；fina_mainbz需核实P/D类别及旧碰撞，不把旧物理键当已确认业务键。
5. Tushare、外部来源、L2、QMT、内部结果、View/MV分别定义来源任务，不能要求所有对象虚构Tushare API。
6. 公共功能按职责验收，F001只读基线不启动写入；数据任务仍须真实来源与QuestDB闭环，mock仅证明实现测试。
7. 每项完成记录与用户人工复核分离，AI不代填accepted；来源/权限/键不明时blocked，不用降低标准保证成功。
