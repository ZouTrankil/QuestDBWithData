## 对账结果

- 现货日小时：2465 天全部字段一致，15 天小时数不足，4 天成交字段不一致；OHLC 没有发现差异。
- 四天为 `2021-01-21`、`2021-04-23`、`2021-12-24`、`2022-04-13`。原始值都留着，日小时联合分析先跳过这些天的成交字段。
- 现货小时源有一条“结束早于开始、全价相同、零成交”的坏占位行，已隔离，算在 32 根缺口里。其他缺口不填价格，原因未核实的不说成合法停市。
- 58 次资金费率事件缺少四种已结束小时价之一，关联值留空。起点前的行情不在本次范围，来源缺口也不向前补值。
- API 与月包重叠一天的三次结算时间、费率一致。10 月尾部 57 次已正式补入；间隔未知留 null，月包原有间隔不变。
