# F015 写入组合预检（进行中）

新增 `WriteGroupRequest` 和 `WriteGroupPlan`：每组显式批次身份、逻辑日期，每成员保留数据集版本及独立批次身份。一个数据集只出现一次，重复成员须显式合并其 rows。每成员最多 10000 行、全组最多 64 成员和 100000 行。每成员规范化数据最多 16 MiB、全组 64 MiB。

预检复用 `DatasetWritePreparation`，要求注册定义支持 WRITE，并且为具有指定时间戳、WAL 和完整去重键的 TABLE；View/MV 拒绝。完整列、null、Java 日期/时间类型和主键重复在发送前检查。输入行以 DatasetValues 保存，保留严格类型及二进制防御性复制。

组指纹绑定稳定批次身份、逻辑日期、成员顺序、完整数据定义、owner 解析的目标身份和行数据指纹。无序 map/capability 集合先规范化，避免进程重启后顺序差异导致指纹变化。预检不接触 writer，也不声称已写入或通过回读；空批次保留 empty，不能代替非空数据验收。
